# 欢迎来到 RetroVault

**RetroVault** 是一个经典复古游戏模拟器平台，构建于现代 Web 之上。我们托管了 **2324 款游戏**，涵盖 NES、Game Boy、SNES、街机等平台 — 全部可在浏览器中直接畅玩。

## 特色

- **无需下载安装** — 通过 EmulatorJS 在浏览器中运行
- **跨平台** — NES、SNES、Game Boy、Game Boy Advance、N64、街机、世嘉等
- **存档功能** — 随时保存进度，随时继续
- **游戏队列** — 创建游玩会话，连续畅玩
- **极速体验** — 由 Cloudflare 全球 CDN 提供加速

## 热门平台

| 平台 | 游戏数量 | 代表作 |
|------|---------|--------|
| NES | 800+ | 超级马力欧、洛克人、塞尔达传说 |
| Game Boy Advance | 400+ | 宝可梦、银河战士、恶魔城 |
| SNES | 350+ | 超级马力欧世界、时空之轮 |
| 街机 | 300+ | 街头霸王 II、吃豆人 |

## 快速开始

1. 浏览[游戏库](/zh/games)
2. 点击游戏卡片查看详情
3. 点击绿色 **Play** 按钮开始游戏
4. 使用浮动操作按钮 (FAB) 管理你的队列

> **提示：** FAB 按钮会跟随你在页面间移动 — 将游戏加入队列后可以连续畅玩。
