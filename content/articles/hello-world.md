# Welcome to RetroVault

**RetroVault** is a classic retro game emulator platform built for the modern web. We host **2324 games** across platforms like NES, Game Boy, SNES, Arcade, and more — all playable directly in your browser.

## What Makes RetroVault Special?

- **No downloads, no plugins** — games run in-browser via EmulatorJS
- **Cross-platform** — NES, SNES, Game Boy, Game Boy Advance, N64, Arcade, Genesis, and more
- **Save states** — pick up where you left off
- **Play queue** — build a session and play through your favorites
- **Fast** — served from Cloudflare's global CDN

## Getting Started

1. Browse the [game library](/games)
2. Click any game card to see details
3. Hit the green **Play** button to start
4. Use the floating action button (FAB) to manage your queue

> **Tip:** The FAB follows you across pages — add games to your queue and play them in sequence.
